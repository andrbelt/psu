# Локальная копия шапки и футера ПГНИУ

Откройте `index.html` (подбор программ для абитуриентов) или `program.html` (страница программы) в браузере. Установка зависимостей не нужна.

Сохранена разметка шапки, раскрывающегося меню, поиска и полного футера из предоставленного `1.mhtml`. На `index.html` размещена форма подбора; `program.html` содержит страницу программы «Прикладная математика и информатика».

## Файлы

- `index.html` — страница раздела «Абитуриентам» с подбором программ.
- `program.html` — страница образовательной программы. Обе страницы используют общую папку `assets/`.
- `assets/css/` — стили, извлечённые из MHTML, и локальные дополнения в `local.css`.
- `assets/js/main.js` — восстановленная работа меню, подразделов и поиска, закрытие по Escape и управление фокусом.
- `assets/css/admissions.css` — оформление формы и горизонтальных карточек в палитре и шрифтах ПГНИУ; на телефоне карточки перестраиваются в одну колонку.
- `assets/js/admissions-core.js` — сопоставление программ, экзаменов и фильтров.
- `assets/js/admissions.js` — форма, подсказки и карточки результатов.
- `assets/json/admissions.json` — исходные данные, включая справочник факультетов `catalogs.faculties` и связи `programs[].facultyIds`; `admissions.schema.json` — их схема.
- `assets/images/` — полный предоставленный `icons.svg` и изображения, извлечённые из CSS.
- `assets/fonts/` — все шесть предоставленных OTF-шрифтов, встроенные шрифты из CSS и файл авторских прав.
- `scripts/extract_page.py` — скрипт извлечения из исходных файлов по указанным в нём путям; нужен только для повторного создания копии.

Все ресурсы оформления локальные. Используемые символы спрайта также встроены в HTML, чтобы логотипы и иконки отображались при открытии через `file://`.

MHTML не содержит исходных JavaScript-файлов сайта: локальный скрипт создан заново для элементов шапки. Поиск отправляет запрос на `https://psu.ru/search/`, ссылки навигации и версия для слабовидящих открывают исходный сайт и требуют интернета.

Сохранённые исходные CSS оставлены целиком, включая правила для других разделов сайта. Неиспользуемые внешние Google Fonts не подключаются: шапка и футер используют приложенные Permian.

## Подбор программ

Три режима: «По предметам ЕГЭ», «По специальности» и «По факультетам». Русский язык выбран обязательно и не снимается; для подбора по предметам нужно ещё минимум два предмета, без верхнего ограничения. Пока выбрано меньше двух, отображается весь каталог с учётом дополнительных фильтров. Выбранные предметы и факультеты обозначаются минусом, невыбранные — плюсом. Результаты обновляются при изменении выбора; кнопка «Показать программы» проверяет выбор и прокручивает к результатам.

При альтернативных экзаменах достаточно одного из перечисленных. ДВИ не считается предметом ЕГЭ и отдельно подписано в карточке. Подбор по ЕГЭ проверяет доступные конкурсы; при включении «Есть платные места» проверяются именно требования платного конкурса. Фильтры форм обучения объединяются через «или»; ни одной выбранной формы означает все формы.

Автозаполнение ищет по названию, направлению, коду и сокращениям `searchAliases`. Подсказку можно выбрать мышью или стрелками и Enter; Escape закрывает список. Каждая карточка соответствует отдельной форме обучения. Проходные баллы бюджета и платного конкурса показаны отдельно за 2026 год; места берутся из `plannedPlaces` на 2027 год, а не из числа зачисленных в 2026 году. Отсутствующие баллы не заменяются нулём.

Факультеты выбираются без ограничения; достаточно принадлежности программы к любому из выбранных факультетов. При пустом выборе показаны все факультеты. Всего в текущем каталоге 13 программ, 17 вариантов обучения и 11 факультетов/институтов.

Карточка целиком является ссылкой на `program.html`. В ней сначала показаны места, затем проходные баллы, после них стоимость; календарные годы в подписях не выводятся. Показано не более 10 карточек за раз. При изменении любого фильтра выдача возвращается на первую страницу.

В исходном JSON каталог по-прежнему помечен как прототип: прежние стоимость, план мест и экзаменационные требования демонстрационные. По просьбе пользователя абзац об этом из интерфейса удалён. Соответствия факультетов и три дополнительные программы (геология, история, физика) внесены по приложенным итогам приёма ПГНИУ за 2026 год. Проходные баллы и числа зачисленных сохранены как исторические результаты. Будущие места, стоимость, коды и требования к экзаменам в PDF отсутствуют: для новых программ они оставлены `null` и отображаются как неизвестные. Эти программы доступны в поиске по специальности и факультетам; по ЕГЭ они не предлагаются до заполнения требований. Фильтр платных мест также требует известного положительного плана мест.

Скрипт `scripts/update-catalog.cjs` воспроизводит дополнение данных и схемы; `node scripts/prepare-data.cjs` затем обновляет резервную копию для `file://`. Заочная геология из PDF относится к поступающим на базе СПО и в каталог для школьников не добавлена.

При работе через HTTP страница читает JSON напрямую. Для открытия двойным щелчком без сервера используется автоматически созданный `assets/js/admissions-data.js`. После изменения JSON обновите его командой:

```powershell
node scripts/prepare-data.cjs
```

Проверки:

```powershell
node --test scripts/admissions.test.cjs
```

В браузере проверены подбор по биологии и химии, исключение программ без платных мест, поиск и выбор подсказки с клавиатуры, заочная форма, пустой результат и сброс. После правок дополнительно проверены выбор нескольких факультетов, выдача 10 и 7 карточек на двух страницах, подписи данных и переход с карточки на `program.html`. Проверены ширины 1280 и 390 px. Прямое открытие `file://` не проверено браузерной автоматизацией из-за ограничения её политики; соответствие резервного набора исходному JSON проверяется тестом. Все 13 тестов логики подбора проходят.

Скрипт `scripts/extract_page.py` создаёт исходную оболочку из MHTML и защищён от перезаписи страницы с готовой формой.

## Страница программы

Структура `program.html` сохраняет исходный референс, содержание заменено на программу ПГНИУ «Прикладная математика и информатика» из предоставленного `2.mhtml`.

Используются только локальные стили ПГНИУ и дополнения `assets/css/program.css`, ограниченные страницей программы. Исходная разметка шапки и футера сохранена; скрипт сборки проверяет их неизменность. CSS КФУ и сторонние скрипты не подключаются.

Описание, два профиля, ЕГЭ с минимальными баллами, дисциплины, компетенции, работодатели и контакты взяты из вложения. Указаны 90 бюджетных и 3 платных места, стоимость 215 000 рублей за 2026/2027 учебный год. Проходные баллы 201 и 172 за 2026 год взяты из ранее предоставленного PDF с итогами приёма. Эти сведения не меняют демонстрационный каталог в `admissions.json`.

Исходный раздел преподавателей референса и все ссылки на сайт КФУ удалены. По указанию пользователя разделы без сведений во вложении (цели программы, научная деятельность, базы практик, международное сотрудничество, испытания для СПО) сохранены; их содержимое пока служит заполнением структуры и не подтверждено для новой программы.

Логотипы работодателей сохранены локально из официальных источников: ЭР-Телеком — официальный карьерный сайт `rabotaertelecom.ru`, ПНППК — `pnppk.ru`, Тен.Лаб — `ten-lab.ru`. Их точные адреса зафиксированы в `program-detail.json`. Белые версии ПНППК и Тен.Лаб размещены на тёмной подложке.

- `assets/json/program-detail.json` — данные программы, профилей, экзаменов, работодателей и контактов.
- `assets/images/program/` — локальные изображения и логотипы; прежние неиспользуемые фотографии не подключаются к странице.
- `assets/js/program.js` — активный раздел меню, вкладки дисциплин и ленты карточек с кнопками и управлением с клавиатуры.
- `scripts/build-program.cjs` — прежняя сборка из данных и шаблона. Для текущей версии отключена защитой от перезаписи ручных правок.
- `scripts/import-psu-program.py` — первоначальный импорт данных из пользовательского `2.mhtml`; не обновляет вручную отредактированное содержимое текущей страницы.

Проверки ресурсов и неизменности шапки/футера выполняет `scripts/check_assets.py`.
